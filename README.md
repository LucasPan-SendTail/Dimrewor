## 更新日志

### [v1.0] — 2026-11-18（正式版）

#### 新增
- **终末之诗**：通关后滚动播放 ENDPOEM，带淡入淡出与停留帧
- **三色选中框**：放置（绿）/ 破坏（红）/ 交互（蓝）状态分别用不同颜色高亮
- **结构化日志系统**：带采样轮转，硬件信息记录（`/hw` 指令），F3 面板同步显示 CPU、内存
- **低性能优化模式**：30FPS 塌陷节流、云朵 / 星空预渲染
- **可滚动关于界面**：支持鼠标滚轮浏览项目信息
- **交互距离 5 格**：`dx² + dy² ≤ 25` 欧几里得距离检测（替代原曼哈顿 ≤ 6）
- **硬件信息面板**：F3 中显示 CPU 核心数、内存等硬件信息

#### 修复
- **塌陷首帧不扫描**：`_collapse_tick` 从 0 改为 1，确保沙土第 1 帧即响应物理
- **`poem_total_height` 未声明**：在 `__init__` 中补初始化为 0，防止 AttributeError
- **`try_select_block` 死代码**：删除末尾不可达的 `return False`
- **`_hover_line` 显示缺空格**：`id={bid}==可交互` → `id={bid} 可交互`
- **日志轮转静默失败**：`os.replace` 异常改为 `print` 留痕，便于排查磁盘 / 权限问题
- **鼠标贴边提示文字飞出屏幕**：`draw_hover_box` 中标签坐标 clamp 到视口内
- **字体特殊符号乱码**：清除所有会被渲染的非常见符号（`²`、`·`、`→`、`×` 等），统一替换为 ASCII 安全字符，F3 面板 `d2<=25`、关于页 `CPU 8 核 | 标准模式`、核心提示 `紫色 -> 右键 -> 红色`

#### 调整
- 窗口锁定 1000×600，正式发布版
- 终末之诗滚动速度随 `target_fps` 缩放
- 日志备份保留数量与轮转策略固化
- 指令集维持四条锁定，正式版不再增删
- `_build_star_field` 全局变量补"仅主线程"注释
- `wrap_text` 英文长词换行逻辑优化

## 运行要求
- Windows 7 及以上
- Python 3.8+（源码运行）或直接使用打包版 exe
- 依赖：`pygame>=2.0.0`

## 操作说明
| 按键 | 功能 |
|------|------|
| WASD | 移动 |
| SPACE | 跳跃 / 菜单确认 |
| 鼠标左键 | 破坏方块 |
| 鼠标右键 | 放置方块 |
| 数字键 1-9 | 选择方块 |
| F3 | 调试信息 |
| H | 关于界面 |
| ESC | 返回菜单 |
