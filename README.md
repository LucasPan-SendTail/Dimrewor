## 更新日志

### [v1.0-upcut3-26P3] — 2026-11-16

#### 新增
- **主菜单动态背景**：天空渐变 + 日月弧线 + 星星 + 3朵像素云飘动，菜单状态实时驱动
- **菜单UI升级**：
  - 标题黑色描边 + 副标题版本号
  - 开始/关于按钮圆角矩形，hover 变色反馈，文字不溢出边框
  - 右下角控制说明面板（半透明），左下角版本标识
- **菜单按钮双触发**：键盘快捷键（SPACE / H）+ 鼠标左键点击，等价触发
- **F3 调试界面**：实时显示玩家坐标、逻辑坐标、速度、摄像机偏移、时间、飞行状态、选中方块、FPS
- **指令系统**（锁定四条，不增删）：
  - `/tp x y` — 传送到指定逻辑坐标
  - `/time` — 显示当前天数、帧数（17280帧/天）、格式化时间
  - `/time 加速倍数` — 设置时间流速倍率
  - `/fly true/false` — 切换飞行模式
- **昼夜循环**：288秒/天，天空颜色与暗度平滑渐变，日月沿弧线运动
- **月相系统**：30天周期，8种月相像素绘制
- **星空背景**：夜间随机60颗星星，透明度随昼夜因子变化
- **飞行模式**：WASD移动 + SHIFT加速，无视重力
- **关于界面**：独立页面，展示项目信息与致谢（与文档同步）

#### 修复
- **菜单按钮文字溢出**：宽度余量 `+60` → `+120`，字体 36px → 22px（hint_font），文字居中不破框
- **菜单按钮无法鼠标点击**：新增 `menu_btn_start` / `menu_btn_about` 矩形属性，每帧同步坐标尺寸，`MOUSEBUTTONDOWN` 中 `collidepoint` 检测，键盘+鼠标双触发生效
- **day_count 递增**：改为 `day_time` 累加到 288 时归零并递增
- **`/time` 返回值**：无参数时输出"第N天 第M帧/17280 HH:MM"格式
- **玩家碰撞体**：20×40 → 32×64
- **跳跃力度**：12 → 7（手感优化）
- **交互距离**：改为曼哈顿距离 ≤6 格检测，防止隔空操作

#### 调整
- 窗口锁定 1000×600，60FPS
- 日月弧线参数：`arc_height = screen_h - 40`、`horizon_y = screen_h - 20`、`arc_width = screen_w × 0.85`
- 正午/子夜日月贴顶，日出/月落贴底
- 指令集锁定，后续版本不得增删上述四条
